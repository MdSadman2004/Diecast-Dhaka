# Asset provenance

- Vehicle geometry, wheels, glazing, interiors, track and podium: authored procedural Three.js geometry in `src/cars.js`. The six models are illustrative silhouettes with separate dimensions/profile data. They are not licensed manufacturer CAD, exact Mattel castings, scans or authenticated product photographs.
- Product images: generated at runtime on this machine from the same model factory. No remote stock photos, external model downloads, image-generation APIs or copied product photos are used.
- Page, logo, SVG favicon: authored for this project. Working business name is a concept, not verified registration.
- Type: Barlow and Barlow Condensed, self-hosted via @fontsource packages, SIL Open Font License. Package license files remain in node_modules; the build serves only local font assets.
- Icons: Lucide, ISC license, locally bundled selected symbols.
- Engine: Three.js, MIT license. Vite and Node dependency licenses remain applicable.
- Screenshots in qa/ and .impeccable/review/: actual locally served website captured with Playwright via the explicitly authorized D:/MCP/chrome-real-profile. No user account pages or third-party media are included.
- Hot Wheels, Mattel and vehicle brand/model names: trademarks of their respective owners. The site states it is an independent reseller concept; it uses no official Hot Wheels logo or claimed authorization.
